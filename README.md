# English-app — Speak 1 Minute

เว็บแอปฝึกพูดภาษาอังกฤษแบบง่าย: สุ่มหัวข้อ แล้วพูดให้ครบ 1 นาที ใช้บน iPad ได้ทั้งแนวตั้งและแนวนอน

## ฟีเจอร์
- สุ่มหัวข้อจาก 39 หัวข้อ ใน 6 หมวด (เลือกหมวดได้) พร้อมคำแปลไทย
- คำถามช่วยคิด (hint) กดเปิด/ปิดได้
- ตัวจับเวลา 1 นาที แบบวงกลม เริ่ม / หยุดชั่วคราว / เริ่มใหม่ ช่วง 10 วินาทีสุดท้ายเปลี่ยนเป็นสีส้ม
- มีเสียงเตือนเมื่อหมดเวลา และกันหน้าจอดับระหว่างจับเวลา (ถ้าเบราว์เซอร์รองรับ)
- นับจำนวนครั้งที่ฝึกในวันนี้ (เก็บไว้ในเครื่อง)

## ไฟล์
- `index.html` — โครงหน้าเว็บ
- `style.css` — หน้าตา รองรับจอ iPad, โหมดมืด
- `topics.js` — คลังหัวข้อ (เพิ่มหัวข้อใหม่ได้ที่นี่)
- `app.js` — การทำงานของการสุ่มและตัวจับเวลา

## วิธีใช้บน iPad
เป็นไฟล์ HTML ล้วน ไม่ต้องติดตั้งอะไร นำไปโฮสต์ เช่น GitHub Pages
(Settings → Pages → Deploy from a branch → เลือก `main` / root) แล้วเปิดลิงก์ใน Safari
จากนั้นกด แชร์ → "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้เหมือนแอป
